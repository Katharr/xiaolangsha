# P1 整改方案：AI 反趋同 / 反复读机（会话交接文档）

> 新会话直接读本文件即可开工。前置背景见 `CLAUDE.md`。本方案承接上一轮 P0
> （女巫用毒纪律，commit `b77eadd` 已上 main）之后的 P1 工作。

## Context（为什么做这个）

用户试玩 7 人标准局暴露两个 AI 质量问题：

- **现象 A — 羊群投票**：第一天 6 个 AI 全票抗推同一个人。
- **现象 B — 发言复读机**：1/2/3 号发言高度雷同，连 AI 自己都在发言里吐槽"2、3 像复读机"。

**经代码追查，这两个现象同源，且不是数据泄漏 bug：**

1. 投票是**暗投**，结算前互相看不到票（`src/rules/visibility.ts:134-160` `collectVisibleVotes`：非自己的票在 `vote_resolved` 前被过滤掉），所以**根本不是"看票跟票"**。
2. 真正根因：**persona 系统只是"说话风格调味"，不影响判断**。
   - `src/shared/personas.ts:9` 注释明确："性格只是说话风格的调味，不含任何身份/阵营信息"。
   - `src/ai-proxy/handler.ts:104` 注入时只说"说话时自然地流露这种性格，但别刻意表演"。
   - 即：persona 决定**怎么说话**，不决定**怎么判断/怎么权衡证据**。于是所有 AI 用同一个模型 + 同一套推理提示 + 读同样的公开发言 → **各自独立地得出相同结论** → 全票同一人、发言论点高度雷同。
3. Stage A 的去偏见（`shuffledTargets`，`handler.ts:162-186`）只覆盖了**夜晚行动和投票**的候选顺序，**发言任务（`speech`，`handler.ts:242`）没有任何去偏见 / 反复读 / 视角多样化**。

**一句话**：人设是"化妆"（音色），不是"性格"（判断倾向）。要让 AI 自然产生分歧，得让不同座位**在判断层面就不同**，而不只是语气不同。

## 设计红线（沿用 P0 的共识 + persona 既有约束）

- **判过程不判结果**：目标是让 AI 各自**基于自己的判断倾向**独立推理，从而自然分歧；不是硬塞随机噪声、也不是强行打散票型。分歧必须是"想法不同"，不是"为了不一样而乱投"。
- **不泄漏身份/阵营**：新增的"判断倾向"轴必须和阵营无关、对任何身份都适用（和 persona 同款约束，见 `personas.ts:9`）。真人玩家仍不能借此被认出。
- **不破坏存档复现**：`NAME_POOL` 的键顺序被 `personas.test.ts` 锁定（影响 `seededShuffle` 的名字分配）。**新增内容不得改动 `NAME_PERSONAS` 的键或其顺序**——用并行的新映射、或在 value 里追加，别动键序。
- **可见信息 / 规则层 / schema 不动**（守 ISO 红线）。改动集中在 `ai-proxy` 提示装配 + `shared/personas`。

## 推荐方案：给人设加一条"判断倾向"轴（认知人设）

核心一招，同时治趋同和复读机：**把 persona 从"只调语气"升级为"也调判断倾向"**，并让它流进 `reasoningInstruction` / `vote` / `speech` 提示。

### 1. 新增"判断倾向"维度（`src/shared/personas.ts`）

新增一个与名字同源的并行映射（**不改 `NAME_PERSONAS` 键序**），给每个名字一条**阵营中立**的思维倾向，例如（择一组，需可区分、覆盖谱系）：
- 多疑 / 易信任
- 重逻辑链条 / 重第一直觉
- 激进先手归票 / 谨慎压票观望
- 看重票型站边 / 看重发言细节

导出 `dispositionForName(name): string`，未知名字回退中性，**绝不抛错**（仿 `personaForName`）。补 `personas.test.ts`：每名字都有倾向、键序不变、未知回退。

> 备选：不加新映射，直接把倾向并入 `NAME_PERSONAS` 的 value 字符串（改 value 不改 key，不破坏复现）。更省事但语义没那么干净，二选一即可。

### 2. 把判断倾向注入"推理 + 投票 + 发言"提示（`src/ai-proxy/handler.ts`）

- 在 `reasoningInstruction()`（`148-155`）或 system 段（`104` 附近）加一句：`你判断局面的倾向：${dispositionForName(vi.ownName)}。按这个倾向去权衡证据、形成你自己的判断，不必和别人一致。`
- **`vote` 指令**（`225-233`）已有反跟风文案，补一句"你和别人结论不同很正常，按你自己的倾向投，不用凑大流"。
- **`speech` 指令**（`242`，**当前最薄弱**）补两点：
  - **反复读**：`别附和/复述前面发言的人，给出你自己的独立观点；如果你的判断和前面的人不同，直接说出来。`
  - **去偏见**：让 `speech` 也走 `shuffledTargets`（目前 speech 没有 `targetsHint`，需评估发言任务要不要给候选顺序提示；至少在提示层强调"别按发言顺序/座位顺序选怀疑对象"）。

### 3.（可选，低优先）按座位扰动采样温度

在 `handler.ts` 调 LLM 处，按 `vi.ownSeat` 给一个**确定性**的小幅 temperature 偏移（复用 `shuffledTargets` 同款 FNV+xorshift 种子，保证可复现），给同质模型再加一点随机分歧。**先做 1+2，不够再上这条**——避免一次改太多说不清谁起的作用。

## 改动文件清单

- `src/shared/personas.ts` —— 新增判断倾向映射 + `dispositionForName`。
- `src/shared/personas.test.ts` —— 补测试（键序锁定、全覆盖、未知回退）。
- `src/ai-proxy/handler.ts` —— 注入倾向到 reasoning/vote/speech；强化 speech 反复读+去偏见。
- （可选）`handler.ts` LLM 调用处 —— 按座位扰动温度。

## 验证（人工试玩为主，对应两个现象）

`npm run dev` 开 7 人标准局，多开几局看复盘的发言记录 + 投票记录：

1. **反趋同**：第一天投票**不再 6 人全压一个**（出现合理的票型分散），且分散是"想法不同"而非乱投——看每个 AI 的 `decisionSummary` 是否各自给出基于自身倾向的理由。
2. **反复读**：1/2/3 号发言**论点和措辞明显不同**，不再是"平安夜别盘死 + 预言家有查杀就跳"的同模板复述。
3. **回归**：`npx tsc -b` 通过；`npm test` 全绿（注意 `personas.test.ts` 的键序断言不能破）。
4. **复现不破**：同 `gameId` 重开/恢复存档，结果仍可复现（温度扰动若加，必须用确定性种子）。

## 明确不做

- 不动投票暗投机制（本就正确，趋同不是它造成的）。
- 不改 `NAME_POOL` 键序（破坏存档复现）。
- 不在 persona/倾向里掺任何身份或阵营信息。
- 不碰规则层 / 可见信息 / schema。
- 不做女巫毒药相关（P0 已单独处理，见 commit `b77eadd`）。
