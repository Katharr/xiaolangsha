## 锁定决策

1. 后续 AI Agent 必须先读取 `ProjectStatus.md`，再按任务类型读取阶段文档。
2. `Agent.md` 是阶段推进、Developer Agent、Reviewer Agent 和 HITL 机制的项目级约束。
3. `Skill.md` 是后续 AI Agent 的项目启动与上下文加载规则。
4. 阶段6编号化验收用例是阶段9开发与审查的强制依据，不是建议清单。
5. 缺少验收编号、缺少验证证据、违反模块边界或破坏信息隔离时，Reviewer Agent 必须驳回。
6. `docs/archive/` 默认不得读取，除非项目负责人明确要求追溯历史、查看归档、查看调研来源或查看讨论过程。
7. 阶段9开始前不得进入业务编码；阶段8必须先拆分开发切片。

## 待验证事项

1. 阶段8需要验证 `Agent.md` 中的 Developer/Reviewer 交接格式是否足以支撑具体开发切片。
2. 阶段8需要验证第一轮可运行骨架的切片粒度是否足够小，能让每个切片独立实现、独立审查、独立关联阶段6验收编号。
3. 阶段9开始后，需要通过真实 Developer Agent 与 Reviewer Agent 流程验证驳回单、通过单和 HITL 门禁是否执行顺畅。

以上事项只影响后续执行细节，不影响阶段7已锁定的项目治理原则。若阶段8发现规则缺口，应生成回溯清单修正阶段7。
