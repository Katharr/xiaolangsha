# 07 R7 扩展角色与板子

## 目标

在人类平民视角和 LLM 对抗体验被验证后，逐步扩展到更多人类可玩角色和更多板子。

长期目标是所有常见板子、所有角色都可玩，但必须分阶段接入，每个角色都要有独立可玩闭环和信息隔离测试。

## 范围

本阶段按后续优先级逐步实现：

- 人类狼人体验。
- 人类预言家体验。
- 人类女巫体验。
- 更多规则集配置。
- 角色专属 UI 和行动流。

本阶段不一次性实现：

- 所有扩展角色。
- 排行榜。
- 多人联机。
- 账号系统。
- 商业化。

## 扩展原则

- 新角色通过规则配置和状态机扩展，不复制整套规则引擎。
- 新角色必须定义自己的玩家视角、LLM 视角和合法行动列表。
- 新角色必须补充多视角信息泄露矩阵测试。
- 人类可玩角色必须有清晰 UI 行动入口。
- LLM 玩家不能因为新角色获得额外隐藏信息。

## 验收标准

- 每个新增人类角色都有完整行动闭环。
- 每个新增角色都有信息隔离测试。
- 新板子不破坏 `quick-6-v1`。
- LLM 请求上下文仍只包含当前视角允许的信息。
- 规则引擎仍是唯一权威裁判。
