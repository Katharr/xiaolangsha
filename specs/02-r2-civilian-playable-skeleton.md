# 02 R2 人类平民视角可玩骨架

## 目标

做出新版 MVP 的第一条可玩骨架：人类玩家以平民身份完成一局 6 人快速局，AI 玩家补齐其他座位，本地规则引擎完成权威结算。

本阶段验证“能不能玩完一局”，不追求 AI 发言已经很聪明。

## 范围

本阶段实现：

- 默认人类玩家为平民。
- 5 名 AI 玩家由 LLM 玩家协议驱动，失败时走弱脚本兜底。
- 夜晚阶段由 AI 玩家提交合法行动候选，本地规则结算。
- 白天阶段展示公开死亡、AI 发言、玩家发言入口、投票和放逐。
- 游戏结束展示胜负和身份揭晓。
- 基础 API key 缺失提示或开发模式提示。

本阶段不实现：

- 人类狼人、预言家、女巫玩法。
- 自由文本发言。
- 深度复盘和评分。
- 多板子。
- 局内教练。

## 体验要求

- 首屏直接进入训练桌或可开始训练，不做营销页。
- 玩家始终知道自己是谁、现在是什么阶段、轮到谁行动。
- AI 思考时需要有清晰状态，不让用户误以为卡死。
- LLM 调用失败时系统能提示并兜底，不中断整局。
- 一局目标时长控制在 10 分钟内。

## 验收标准

- 人类平民可以完整玩完一局 `quick-6-v1`。
- AI 玩家行动均来自合法行动候选或兜底合法行动。
- 本地规则引擎负责所有死亡、放逐和胜负结算。
- UI 不直接读取完整 `GameState`。
- 游戏结束后展示获胜阵营和所有身份。
- Playwright 冒烟测试覆盖开局、至少一个白天投票、游戏结束路径。
