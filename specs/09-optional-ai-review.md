# 09 可选 AI 赛后复盘

## 目标

添加可选 AI 赛后复盘，让 LLM 基于完整赛后数据给出更自然的教练讲解。

## 范围

本阶段是可选增强。无 API key 时游戏、评分和脚本复盘必须照常运行。

## AI 复盘输入

AI 复盘可以使用赛后数据：

- 完整时间轴。
- 身份揭晓。
- 玩家评分。
- 脚本复盘。
- 胜利条件。
- 人类玩家角色和阵营。
- 人类玩家行为和决策。

AI 复盘不得修改：

- 游戏结果。
- 时间轴。
- 脚本评分。
- 脚本复盘事实。

## 必要行为

AI 复盘应解释：

- 玩家行为是否符合角色定位。
- 玩家是否帮助己方阵营。
- 玩家是否打击敌方阵营。
- 赢局中最佳回合或决策。
- 输局中起反作用的回合或决策。
- 具体的下局建议。

## API 和成本控制

- 功能默认关闭。
- 需要显式配置 API key。
- 提示 AI 复盘可能消耗 token。
- 提供每次复盘调用上限。
- AI 调用失败时，脚本复盘仍然可见，并显示非阻塞错误。

## 安全规则

AI 复盘发生在赛后，可以使用揭晓信息，但不能声称这些信息在对局中已经可见。

提示词必须区分：

- 玩家当时知道什么。
- 赛后揭晓了什么。
- 哪些建议适用于下一局。

## 测试要求

添加测试覆盖：

- 没有 API key 不会破坏复盘。
- AI 复盘请求只序列化赛后复盘载荷，不序列化原始完整 `GameState`。
- AI 复盘失败时返回回退状态。
- 脚本评分不会被 AI 复盘改变。

## 验收标准

- AI 复盘只有配置后才能启用。
- 没有 AI 复盘时，游戏仍然完整可用。
- AI 复盘文本明确标注为可选 AI 复盘。
- 玩家能看到 token 成本风险提示。

## 不在本阶段范围

- LLM 局内玩家决策。
- LLM 发言层。
- 替换脚本评分。
