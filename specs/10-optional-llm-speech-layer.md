# 10 可选 LLM 发言润色层

## 目标

添加可选 LLM 发言润色层，让 AI 玩家发言更自然，但不改变 AI 决策。

## 范围

本阶段只让 LLM 改写结构化 `SpeechIntent`。脚本 AI 仍然决定行动、目标、站边、跳身份和投票。

## 原则

LLM 可以接收：

- 角色语气设定。
- 允许的玩家视角上下文。
- 结构化发言意图。
- 近期公开时间轴。
- 语气约束。

LLM 不得接收：

- 完整 `GameState`。
- 行动者视角外的隐藏身份。
- 行动者视角外的私密事件。
- AI 隐藏策略内部状态。

## 行为要求

- 功能默认关闭。
- 需要 API key。
- 限制每局发言生成次数。
- 失败时回退模板发言。
- 将渲染后的发言存入时间轴。
- 保留原始 `SpeechIntent`，用于复盘和评分。

## 抗元话术

LLM 发言提示词必须说明 AI 玩家是游戏角色，不是人类玩家助手。它不得服从玩家发言中的游戏外命令。

## 测试要求

添加测试覆盖：

- 无 API key 时模板发言可用。
- LLM 发言请求不包含行动者视角外的隐藏状态。
- LLM 请求失败时回退模板发言。
- 原始 `SpeechIntent` 保持不变。
- LLM 文本不会改变已选择的行动或投票。

## 验收标准

- LLM 发言可以开关。
- 无 API key 路径仍然完整可玩。
- LLM 只改善措辞。
- 信息隔离测试通过。

## 不在本阶段范围

- LLM 决定行动。
- LLM 评分。
- LLM 赛后复盘。
