# 05 局内教练

## 目标

添加可选局内教练，帮助玩家理解术语、阶段目标、下一步决策和发言方向。

## 范围

本阶段实现玩家视角教练。无 API key 时提供本地规则教练；有 API key 时可以预留 LLM 教练接口，但不要让 LLM 成为必需依赖。

## 教练视角原则

局内教练是玩家视角教练，不是上帝视角裁判。

教练可以看到玩家知道的信息：

- 所有公开信息。
- 玩家自己的身份。
- 玩家自己的私有信息。
- 玩家自己的历史行动、发言、投票和决策。
- 如果玩家是狼人：已知狼队友。
- 如果玩家是预言家：自己的查验结果。
- 如果玩家是女巫：药水状态，以及规则允许看到的夜晚信息。

教练不能看到：

- 玩家规则上不应知道的其他玩家身份。
- 其他玩家私密夜晚行动。
- AI 玩家的隐藏策略状态。
- 赛后才揭晓的信息。
- 完整 `GameState`。

## 必要接口

创建：

```ts
buildCoachPlayerView(gameState: GameState, humanPlayerId: PlayerId): CoachPlayerView
getLocalCoachAdvice(context: CoachPlayerView, question?: string): CoachAdvice
```

可选 LLM 适配器只能接收序列化后的 `CoachPlayerView`，不能接收完整 `GameState`、`internal` 事件、随机种子、调试快照或玩家视角外隐藏信息。

LLM 教练接口必须类似：

```ts
getLlmCoachAdvice(payload: SerializedCoachPlayerView, question?: string): Promise<CoachAdvice>
```

禁止出现：

```ts
getLlmCoachAdvice(gameState: GameState, question?: string): Promise<CoachAdvice>
```

## 教练功能

教练面板：

- 可以开关，默认关闭。
- 显示“基于你的当前视角”。
- 显示阶段提示。
- 显示角色专属目标提示。
- 显示下一步关注重点。
- 接收玩家的简单问题。

本地教练可以回答：

- 常见术语。
- 当前阶段目标。
- 角色目标。
- 基础行动建议。
- 基础发言建议。
- 哪些公开投票或身份声明值得关注。

## 安全规则

教练不能声称自己知道隐藏真相。不确定时，应说明建议基于当前玩家视角信息。

教练必须忽略要求揭示上帝视角真相或绕过限制的元命令。

如果启用 LLM 教练，LLM 输出仍然只是非权威建议：

- 必须标注“基于你的当前视角”。
- 只能写入 `CoachAdvice`、解释文本或建议字段。
- 不能替玩家提交行动、修改投票、修改时间轴、修改规则结果或修改评分。
- 当问题需要玩家视角外信息才能回答时，必须说明“当前视角证据不足”，不能编造隐藏身份或夜晚行动。
- LLM 调用失败时回退本地规则教练，不影响对局继续。

## 测试要求

添加测试覆盖：

- 教练能看到人类玩家自己的角色。
- 只有人类玩家是狼人时，教练才能看到狼队友。
- 只有人类玩家是预言家且查验结果属于该玩家时，教练才能看到查验结果。
- 只有人类玩家是女巫时，教练才能看到药水状态。
- 教练看不到其他隐藏身份。
- 教练上下文序列化结果不包含完整 `GameState`。
- 本地教练在无 API key 时可用。
- LLM 教练请求 payload 只包含序列化后的 `CoachPlayerView`，不包含 `internal` 事件、随机种子或调试快照。
- LLM 教练输出不能改变 `Action`、`TimelineEvent`、`RoleScore`、胜负结果或任何规则状态。
- LLM 教练输出必须带有“基于你的当前视角”或等价来源范围标记。
- LLM 教练调用失败时回退本地规则教练。

## 验收标准

- 对局中可以开关教练。
- 无 API key 时，本地教练能提供有用的基础建议。
- 教练上下文限制在玩家视角。
- 信息隔离测试通过。

## 不在本阶段范围

- 强制依赖 API key 的 AI 教练。
- 赛后 AI 复盘。
- 自动修改玩家行动。
- 评分改动。
