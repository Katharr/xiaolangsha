# 05 R5 轻量复盘与可玩性评估

## 目标

在不喧宾夺主的前提下，为新版 MVP 提供轻量复盘和人工可玩性反馈入口，帮助判断方向是否值得继续。

本阶段不做复杂角色评分体系。

## 范围

本阶段实现：

- 胜负结果总结。
- 赛后身份揭晓。
- 关键发言摘要。
- 关键票型摘要。
- 玩家关键投票或判断点评。
- 2 到 3 条下一局建议。
- 简单人工反馈入口，例如“AI 像不像真人”“是否愿意再开一局”。

本阶段不实现：

- 0-100 复杂角色评分。
- LLM 修改评分。
- 深度教学教练。
- 跨局能力画像。

## 复盘原则

- 复盘必须基于时间轴。
- 复盘可以使用 LLM 生成自然语言讲解，但必须是非权威解释。
- 复盘不得修改胜负、规则结算、时间轴或玩家行动。
- 默认赛后复盘不展示 `internal` 事件、原始 LLM payload 或随机种子。

## 验收标准

- 玩家能看到胜负、身份和关键票型。
- 玩家能知道自己最关键的一次投票或判断是否有帮助。
- 复盘没有凭空引用不存在的事件。
- 复盘不包含对局中隐藏但赛后仍不该展示的内部调试信息。
- 人工反馈结果可以用于后续产品判断。
