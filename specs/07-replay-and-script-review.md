# 07 复盘和脚本复盘

## 目标

基于完整时间轴和角色评分，生成赛后脚本复盘。

## 范围

本阶段实现本地脚本复盘，不调用 LLM。AI 复盘作为后续可选增强。

## 复盘视图

赛后复盘必须包含：

- 完整身份揭晓。
- 按时间排序的完整时间轴。
- 公开事件。
- 赛后揭示的私密行动。
- 投票历史。
- 结构化发言意图和渲染后的发言。
- 夜晚行动和结果。
- 胜利条件触发点。
- 玩家评分。

## 脚本复盘内容

为人类玩家生成结构化复盘：

- 角色总结。
- 阵营目标总结。
- 玩家行为是否符合角色定位。
- 玩家是否帮助己方阵营。
- 玩家是否打击敌方阵营。
- 赢局中的出彩点。
- 输局中的反作用点。
- 2 到 5 条下局训练建议。

复盘必须引用具体时间轴事件或具体天数/夜晚编号。

## 和 AI 复盘的区分

使用清晰标签：

- `脚本评分`: 确定性数值评分。
- `脚本复盘`: 确定性规则分析。
- `AI 复盘`: 后续可选的 LLM 教练文本。

脚本复盘不能假装自己是 LLM 生成的。

## 测试要求

添加测试覆盖：

- 游戏结束后，复盘包含完整时间轴。
- 身份只在游戏结束后揭晓。
- 脚本复盘引用真实事件 id。
- 赢局复盘包含亮点部分。
- 输局复盘包含反作用部分。
- 同一份复盘的输出是确定性的。

## 验收标准

- 完成对局后显示复盘和脚本复盘。
- 玩家可以把反馈追溯到时间轴事件。
- 不需要 API key。
- 脚本复盘和 AI 复盘有明确区分。

## 不在本阶段范围

- LLM 复盘。
- 在线分享复盘。
- 高级可视化。
